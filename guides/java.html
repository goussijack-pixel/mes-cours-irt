Ex. 1-I — questions de cours

1. Structure d’un programme Java. Tout le code est dans une classe ; l’exécution commence par la méthode main.

2. Deux avantages de Java sur C++ (deux suffisent) : la portabilité (le même bytecode tourne sur toute machine qui a une JVM) ; la gestion automatique de la mémoire par le ramasse-miettes (garbage collector), donc pas de delete ni de fuites de mémoire classiques ; pas de pointeurs manipulés directement, donc plus de sécurité ; héritage multiple remplacé par les interfaces (plus simple).

3. Deux caractéristiques du constructeur : il porte le même nom que la classe ; il n’a aucun type de retour (pas même void) ; il est appelé automatiquement par new ; il peut être surchargé.

4. Conséquence de la portabilité : un programme compilé une fois (.class) s’exécute sans modification sur Windows, Linux, macOS… (« Write once, run anywhere »). Contrepartie : il faut une JVM installée et l’exécution est un peu plus lente qu’un programme natif.

5. L’outil : la JVM (machine virtuelle Java), qui exécute le bytecode.

Question 1 — les packages
Package (paquetage)

Un dossier logique qui regroupe des classes liées, et qui leur donne un nom complet : la classe Livre du package bj.esgis.bibliotheque s’appelle en entier bj.esgis.bibliotheque.Livre.

Pourquoi les utiliser :

  • Organiser : on range par thème (modele, service, ui), comme des tiroirs.
  • Éviter les conflits de noms : deux classes Date peuvent coexister (java.util.Date et java.sql.Date).
  • Contrôler l’accès : sans public, une classe ou une méthode n’est visible que dans son package.
  • Réutiliser : on importe ce qu’il faut avec import.

Le fichier doit se trouver dans le dossier bj/esgis/bibliotheque/.

Question 2 — les exceptions

Une exception est un objet créé quand une erreur survient pendant l’exécution (division par zéro, fichier absent, indice hors du tableau…). Sans traitement, le programme s’arrête.

  • try : contient le code qui peut échouer ;
  • catch (TypeException e) : s’exécute seulement si cette exception se produit ; on y traite l’erreur ;
  • finally : s’exécute toujours, erreur ou pas (fermer un fichier, une connexion…).

On peut aussi lancer une exception (throw new IllegalArgumentException("…")) et l’annoncer dans la signature (throws IOException).

Chapitre 1 sur 4

Java, la JVM et la structure d’un programme

Java

Un langage orienté objet, compilé puis interprété : javac traduit le source .java en bytecode .class, que la JVM exécute sur n’importe quel système.

SigleContenuPour qui
JVMLa machine virtuelle qui exécute le bytecodetout le monde
JREJVM + bibliothèques standardcelui qui utilise un programme Java
JDKJRE + outils (javac, jar, javadoc)celui qui développe
À retenir

JDK ⊃ JRE ⊃ JVM. La portabilité vient de la JVM : « écrire une fois, exécuter partout ».

Les types de base

int, long, double, float, char, boolean, byte, short (primitifs) ; String est une classe.
