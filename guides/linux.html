Énoncé au propre

I. Questions de cours

  1. Quelle commande permet de modifier la stratégie de mot de passe pour votre compte ? a) chmod b) changemod c) chown d) chage
  2. Lequel de ces caractères passe le résultat d’une commande à une autre commande ? a) > b) >> c) || d) |
  3. Quelle option de find spécifie l’utilisateur propriétaire du fichier recherché ? a) -username b) -user c) --user d) --username
  4. Un fichier a les permissions rw-r--r-x. Quelle est la représentation numérique ? a) 754 b) 645 c) 641 d) 654
  5. Quelle commande change le mot de passe d’un utilisateur ? a) password b) pwd c) paswd d) passwd
  6. Donnez le chemin absolu du fichier qui définit les partitions à monter automatiquement au démarrage.
  7. Qui est l’initiateur du projet GNU ?
  8. Au vu du prompt tobi@kpanlingan:/usr/local#, quel est le nom de la machine ?
  9. Quels sont les modes d’utilisation de l’éditeur vi ?
  10. Avec quelles touches déplace-t-on le curseur dans vi ?
  11. Quelle commande fait le tri numérique croissant du fichier annees.txt ?
  12. Quels sont les 4 principes du logiciel libre ?

II. Exercice

Vous êtes l’utilisateur tobi sur Debian 10 ; le répertoire courant est /home/tobi/.

  1. Créez en une seule commande dans /tmp l’arborescence : partiel contenant session-normale et rattrapage.
  2. Vous avez créé dans rattrapage un fichier notes avec vi et ajouté du texte. Comment enregistrer sans quitter ?
  3. Que se passe-t-il si vous exécutez rmdir /tmp/partiel/rattrapage ?
  4. Affichez la configuration réseau en redirigeant le résultat dans /tmp/partiel/rattrapage/config-reseau.
  5. Retirez-vous tous les droits sur ce fichier.
  6. Vous ajoutez un second disque /dev/sdb pour stocker les journaux. Connectez-vous d’abord en tant que root.
  7. Avec quelle commande créer une partition sur /dev/sdb ?
  8. La partition /dev/sdb1 contient un système de fichiers ext4. Montez-la dans /var/log puis créez le fichier /var/log/testfile.
  9. Après une coupure de courant, la machine redémarre ; ls -l /var/log/testfile répond « fichier introuvable ». Que faire pour y accéder de nouveau ?
  10. Comment éviter ce problème au prochain redémarrage ?

Questions de cours 1 à 8
  1. Un système où plusieurs utilisateurs travaillent (même en même temps), chacun avec son compte, ses fichiers et ses droits, isolés les uns des autres.
  2. Linus Torvalds, en 1991.
  3. Un chemin qui part de la racine / : /home/max/Documents/cours.txt. (Relatif : Documents/cours.txt.)
  4. .. ; un seul point = le répertoire courant.
  5. mv : mv ancien.txt nouveau.txt.
  6. man tail (quitter avec q).
  7. head affiche le début d’un fichier : 10 lignes par défaut ; head -n 5 fichier.
  8. En mode commande : yy copie la ligne ; p colle.
Questions de cours 9 à 15
  1. 3dd supprime (coupe) 3 lignes à partir du curseur.
  2. wc -w fichier (-l = lignes, -c = octets).
  3. grep : grep "root" /etc/passwd (-i, -c, -n).
  4. ext4, ext3, xfs, btrfs ; aussi vfat et NTFS.
  5. fdisk -l (ou lsblk).
  6. /etc/network/interfaces.
  7. Le serveur d’affichage (Xorg ou Wayland), le gestionnaire de fenêtres, l’environnement de bureau (GNOME, KDE, XFCE…).
Exercice, questions 1 et 2
  1. /home/max.

touch crée un fichier vide ; >> ajoute à la fin (> écraserait).

Exercice, question 3 — retirer des droits

De rw-r--r-- (644) on passe à rw-r----- (640) : équivalent chmod 640 comptesutilisateurs.

Exercice, questions 4 et 5 — utilisateur et groupe
Piège classique

Dans usermod -aG, le -a est indispensable : sans lui, -G remplace tous les groupes secondaires.

Énoncé au propre

  1. Pour donner les droits d’exécution sur un fichier, quelle commande lancer ? ○ ls -l fichier ○ chmod +x fichier ○ chmod +x fichiers 0
  2. Principal avantage des commandes terminal pour installer des paquets ou mettre à jour ? ○ plus rapides ○ plus fiables ○ peuvent être automatisées
  3. Après apt-get update, pour mettre à jour la distribution je lance : ○ apt-get upgrade ○ sudo apt-get upgrade ○ supo apt-get upgrade
  4. Qu’est-ce que le terminal sous Linux ? ○ le panneau de configuration ○ une application qui permet de lancer des commandes ○ le gestionnaire de logiciels
  5. Quelle commande donne le taux d’occupation des périphériques de stockage ?
  6. Une distribution Linux, c’est : ○ un noyau Linux et des paquets compatibles ○ un noyau seul ○ les paquets seuls
  7. Quelles sont les 3 premières distributions historiques ?
  8. La philosophie UNIX/Linux, c’est : ○ faire plein de choses en même temps ○ une chose après l’autre ○ faire une chose et la faire parfaitement ○ le plus vite possible
  9. Que permet la licence GPL ? ○ protéger le code source contre le piratage ○ contraindre la libre diffusion ○ garantir l’accès libre au code source
  10. Différence fondamentale entre les environnements de bureau Linux et ceux de Windows/macOS ? ○ les fonctions des environnements Linux sont indépendantes ○ on ne peut pas changer d’environnement sous Linux
