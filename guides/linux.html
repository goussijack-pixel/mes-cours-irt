Module 0 — Linux, GNU et le logiciel libre

Linux

Un noyau de système d'exploitation (le kernel) : le programme qui parle au matériel (processeur, mémoire, disques, réseau) et le partage entre les programmes. Écrit par Linus Torvalds en 1991, quand il était étudiant à Helsinki.

Qui a fait quoi (question d'examen à coup sûr)

QuiQuoiQuand
Ken Thompson et Dennis RitchieUNIX, aux laboratoires Bell (AT&T)1969
Richard StallmanLe projet GNU (un UNIX entièrement libre) et la FSF1983-1985
Linus TorvaldsLe noyau Linux1991

Le projet GNU avait presque tout (compilateur gcc, shell bash, commandes ls, cp…) sauf un noyau. Linux a apporté le noyau manquant : d'où le nom exact GNU/Linux.

Distribution = noyau + paquets

Distribution

Un noyau Linux + une sélection de paquets (logiciels) compatibles + un gestionnaire de paquets pour les installer. Ce n'est ni le noyau seul, ni les paquets seuls.

Les 3 distributions historiques (encore là aujourd'hui) : Slackware (1993), Debian (1993) et Red Hat (1994). La plupart des autres en descendent :

  • famille Debian : Ubuntu, Linux Mint, Kali → paquets .deb, commande apt ;
  • famille Red Hat : Fedora, CentOS, Rocky Linux → paquets .rpm, commande dnf (ou yum) ;
  • Slackware → openSUSE (au départ), et l'esprit « simple et brut ».

Le logiciel libre : les 4 libertés

La licence GPL (GNU General Public License) garantit l'accès libre au code source : quiconque reçoit le programme reçoit aussi le droit de le lire, le modifier et le redistribuer, et ces droits doivent être transmis aux suivants.

  1. Liberté 0 : exécuter le programme, pour n'importe quel usage.
  2. Liberté 1 : étudier son fonctionnement et l'adapter (il faut donc le code source).
  3. Liberté 2 : redistribuer des copies.
  4. Liberté 3 : améliorer le programme et publier ses améliorations.
Libre ≠ gratuit

« Free » en anglais veut dire libre, pas forcément gratuit. Red Hat vend du support pour un logiciel libre ; WhatsApp est gratuit mais pas libre.

La philosophie UNIX

Faire une seule chose, et la faire bien. Chaque commande est petite (sort trie, wc compte, grep cherche) et on les combine avec des tubes | pour faire des choses complexes.

Multi-utilisateur, multitâche

  • Multi-utilisateur : plusieurs personnes peuvent utiliser la même machine en même temps (en local ou à distance par SSH), chacune avec son compte, ses fichiers et ses droits.
  • Multitâche : plusieurs programmes tournent en même temps, le noyau leur partage le processeur.

L'environnement graphique : 3 couches indépendantes

Sous Linux, l'interface graphique n'est pas collée au système comme sous Windows ou macOS : chaque couche se remplace séparément.

  1. Le serveur d'affichage (X Window / Xorg, ou Wayland) : dessine à l'écran, gère souris et clavier.
  2. Le gestionnaire de fenêtres : place, déplace, décore les fenêtres.
  3. L'environnement de bureau (GNOME, KDE Plasma, XFCE…) : panneau, menus, applications de base.
Entraîne-toi
  • Q. Qui est l'initiateur du projet GNU ? R. Richard Stallman (1983).
  • Q. Une distribution, c'est ? R. Un noyau Linux et des paquets compatibles.
  • Q. Différence des bureaux Linux avec Windows ? R. Leurs fonctions sont indépendantes : on peut changer d'environnement de bureau.

Module 1 — Le terminal et l'arborescence

Lire le prompt

Le nom de la machine est entre @ et : (ici kpanlingan). Le signe final dit qui tu es : $ utilisateur ordinaire, # root (l'administrateur).

L'arborescence : tout part de /

Sous Linux il n'y a pas de C: ou D: : un seul arbre qui part de la racine /. Les disques supplémentaires sont montés quelque part dans cet arbre.

DossierContenu
/La racine, point de départ de tout
/homeLes dossiers personnels (/home/tobi)
/rootLe dossier personnel de root
/etcLes fichiers de configuration (passwd, fstab, network/interfaces)
/bin, /usr/binLes commandes (programmes)
/devLes périphériques vus comme des fichiers (/dev/sda, /dev/sdb1)
/varCe qui varie : journaux /var/log, bases, files d'attente
/tmpFichiers temporaires, vidés au redémarrage
/mnt, /mediaPoints de montage (clés USB, disques)

Chemins absolus et relatifs

Chemin absolu

Un chemin qui commence par / : il part de la racine et marche de n'importe où. Exemple : /home/max/notes.txt.

Chemin relatif

Un chemin qui part du dossier courant. Exemple, depuis /home/max : notes.txt ou ../tobi/cours.

Trois raccourcis à connaître : . le dossier courant, .. le dossier parent, ~ ton dossier personnel.

Se déplacer et regarder

  • pwd (print working directory) : affiche le chemin absolu du dossier courant. Pour max dans son dossier personnel : /home/max.
  • ls liste ; ls -l en détail ; ls -a montre aussi les fichiers cachés (ceux qui commencent par un point).
  • cd dossier entre ; cd .. remonte ; cd seul ramène chez toi.

L'aide intégrée

man ouvre le manuel d'une commande (flèches pour défiler, /mot pour chercher, q pour quitter).

Module 2 — Fichiers et dossiers

Créer

  • touch fichier crée un fichier vide sans l'ouvrir (ou met à jour sa date s'il existe).
  • mkdir -p crée les dossiers parents manquants : c'est la clé pour créer une arborescence en une seule commande.
L'arborescence en une commande, version élégante

mkdir -p /tmp/partiel/{session-normale,rattrapage} : les accolades sont développées par le shell en deux chemins.

Copier, déplacer, renommer, supprimer

CommandeEffet

rmdir /tmp/partiel/rattrapage alors qu'il contient le fichier notes → erreur « Directory not empty » : rien n'est supprimé.

Lire un fichier

CommandeCe qu'elle affiche

Chercher

  • grep motif fichier affiche les lignes qui contiennent le motif (-i ignore la casse, -c compte).
  • find cherche des fichiers : -name par nom, -user par propriétaire, -type d les dossiers.
  • sort trie les lignes ; sort -n trie numériquement croissant, sort -nr décroissant.

Module 3 — Rediriger et enchaîner

Chaque commande a une entrée (le clavier) et deux sorties (l'écran : sortie normale et erreurs). On peut les rediriger.

SymboleEffet
>Envoie la sortie dans un fichier en l'écrasant
>>Ajoute à la fin du fichier
<Lit l'entrée depuis un fichier
2>Redirige les erreurs
| (AltGr+6)Le tube : passe la sortie d'une commande à l'entrée de la suivante
À retenir

Le caractère qui passe le résultat d'une commande à une autre est le tube |. || est autre chose (« ou alors » : la 2e commande ne s'exécute que si la 1re échoue).

Module 4 — L'éditeur vi

vi (ou vim) est présent sur tous les systèmes UNIX : en dépannage, c'est souvent le seul éditeur disponible.

Les 3 modes

  1. Mode commande (normal) : au démarrage. Les touches sont des ordres (copier, effacer…), pas du texte.
  2. Mode insertion : i (avant le curseur), a (après), o (nouvelle ligne). On tape du texte. Échap pour revenir.
  3. Mode ligne de commande (ex) : : puis un ordre (:w, :q…) et Entrée.

Les commandes qui tombent à l'examen

yyCopier la ligne courante (yank)
pColler après le curseur

3ddSupprimer 3 lignes à partir de la ligne courante

/motChercher « mot » (n : suivant)
En ligne de commandeEffet
:wEnregistrer sans quitter

:wq ou :xEnregistrer et quitter
:q!Quitter sans enregistrer
Moyen mnémotechnique

Un nombre devant une commande la répète : 5yy copie 5 lignes, 2dd en supprime 2, 10j descend de 10 lignes.

Module 5 — Les droits (permissions)

Lire ls -l

Le 1er caractère donne le type : - fichier, d dossier, l lien. Puis 3 blocs de 3 lettres pour user (propriétaire), group, others.

LettreSur un fichierSur un dossierValeur
rLire le contenuLister son contenu4
wModifierCréer/supprimer dedans2
xExécuterY entrer (cd)1
Convertir en chiffres

Pour chaque bloc, additionne 4, 2, 1 pour chaque lettre présente. rw-r--r-x → 6, 4, 5 → 645. Dans l'autre sens : 754 = rwx r-x r--.

chmod : changer les droits

  • Forme symbolique : qui (u, g, o, a pour tous) + +/-/= + quels droits.
  • Forme numérique : 3 chiffres, comme ci-dessus.
  • chmod +x fichier donne le droit d'exécution (la 1re question du QCM).

chown, chgrp : changer de propriétaire

chmod, chown, chage
  • chmod change les droits ; chown change le propriétaire ;
  • chage change la stratégie de mot de passe (expiration, durée de validité) : chage -l tobi pour la voir, chage -M 90 tobi pour forcer un changement tous les 90 jours.

Module 7 — Disques, partitions et montage

Les noms des disques

Les disques apparaissent dans /dev : sda le 1er disque, sdb le 2e… et les partitions sont numérotées : sdb1 est la 1re partition du 2e disque.

  • lsblk ou fdisk -l : toutes les partitions.
  • df -h : le taux d'occupation des systèmes de fichiers montés (-h = tailles lisibles).
  • du -sh dossier : la taille d'un dossier.

La chaîne complète pour ajouter un disque

  1. Partitionner : fdisk /dev/sdb (n nouvelle partition, w écrire). On obtient /dev/sdb1.
  2. Formater (créer le système de fichiers) : mkfs.ext4 /dev/sdb1.
  3. Monter dans l'arbre : mount /dev/sdb1 /var/log.
  4. Rendre permanent : ajouter une ligne dans /etc/fstab.

Systèmes de fichiers courants : ext4 (le standard Linux), xfs, btrfs, vfat/FAT32 (clés USB), ntfs (disques Windows), swap (mémoire d'échange).

Le fichier qui « disparaît » après un redémarrage

Tu montes /dev/sdb1 sur /var/log, tu crées /var/log/testfile, puis coupure de courant. Au redémarrage : « fichier introuvable ». Le fichier n'est pas perdu : il est sur sdb1, qui n'est plus monté (un mount à la main ne survit pas au redémarrage). ls montre donc le /var/log du premier disque.

Pour que ça n'arrive plus : une ligne dans /etc/fstab, le fichier des montages automatiques au démarrage.

En vrai, on met l'UUID

blkid /dev/sdb1 donne l'identifiant unique de la partition ; UUID=... dans fstab résiste même si les disques changent d'ordre.
