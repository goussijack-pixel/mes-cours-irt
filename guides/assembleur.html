Exercice 1 – Définitions
Assembleur
  1. Le langage assembleur est un langage de bas niveau : chaque instruction (mov, add, jmp…) est une écriture lisible par un humain (mnémonique) d'une instruction machine du processeur.
  2. L'assembleur est aussi le programme (NASM, MASM…) qui traduit ce code en code machine binaire.
Microprocesseur

Circuit intégré qui exécute les instructions d'un programme. Il contient l'unité de commande (elle lit et décode les instructions), l'UAL (elle calcule), les registres (petites mémoires très rapides : EAX, EBX, ESP, EIP…) et les bus qui le relient à la mémoire.

UAL (Unité Arithmétique et Logique)

La partie du processeur qui fait les calculs : addition, soustraction (arithmétique), ET, OU, NON, décalages, comparaisons (logique). Elle met à jour les indicateurs (flags) : zéro, retenue, signe, débordement.

Exercice 2 – Virus et antivirus

Virus : un programme malveillant qui s'attache à un autre programme ou fichier (l'hôte), se reproduit en infectant d'autres fichiers quand l'hôte est exécuté, et peut porter une charge utile nuisible (destruction, vol, ouverture d'accès).

Détection (en 3 lignes) : l'antivirus compare le contenu des fichiers à une base de signatures (empreintes de virus connus). Il complète par une analyse heuristique (code suspect), une analyse comportementale (actions anormales à l'exécution) et parfois un bac à sable.

Opérations sur un fichier infecté

  1. Désinfecter (réparer) : retirer le code viral et restaurer le fichier sain.
  2. Mettre en quarantaine : isoler le fichier chiffré dans un dossier où il ne peut pas s'exécuter.
  3. Supprimer le fichier, s'il ne peut pas être réparé.
  4. Ignorer ou ajouter une exception (faux positif), sur décision de l'utilisateur.
  5. Signaler : journal, alerte, envoi d'un échantillon à l'éditeur.

La pile et la convention cdecl
  • Les arguments sont empilés de droite à gauche : le dernier argument d'abord, le format en dernier.
  • C'est l'appelant qui nettoie la pile après l'appel (add esp, 4 × nombre d'arguments).
Piège classique

On empile message (l'adresse de la chaîne), pas son contenu. Et on oublie souvent le add esp, 8 : la pile serait alors déséquilibrée au ret, et le programme planterait.

Chapitre 1 sur 5

Module 0 — Les mots de l'examen

Assembleur

Un langage de programmation de bas niveau : chaque instruction (mov, add, jmp) correspond presque directement à une instruction machine du processeur. Le mot désigne aussi le programme (NASM, MASM) qui traduit ce code en binaire exécutable.

Microprocesseur

Le circuit qui exécute les instructions d'un programme : il les lit en mémoire, les décode et les exécute, en boucle (cycle fetch – decode – execute). Il contient l'UAL, l'unité de commande et les registres.

UAL (Unité Arithmétique et Logique)

La partie du processeur qui fait les calculs : additions, soustractions, comparaisons, opérations logiques (ET, OU, XOR, décalages). Elle met à jour les indicateurs (drapeaux) : zéro, retenue, signe, débordement.

Les morceaux d'un registre

EAX (32 bits) contient AX (16 bits), qui contient AH (octet haut) et AL (octet bas). En 64 bits, il devient RAX.

Module 3 — La structure d'un programme NASM et l'appel de printf

Les sections
  • section .text : le code (les instructions).
  • section .data : les données initialisées (db = octets, dw = mots de 16 bits, dd = 32 bits).
  • section .bss : les données réservées non initialisées (resb, resd).
  • global _main rend le point d'entrée visible ; extern _printf annonce une fonction de la bibliothèque C.

Chapitre 5 sur 5

Module 4 — Virus et antivirus

Virus

Un programme malveillant qui s'insère dans un autre (programme, document, secteur de démarrage) et se réplique quand l'hôte est exécuté, souvent avec une charge nuisible (destruction, vol, chiffrement).

Comment un antivirus détecte (en 3 lignes)

Il compare les fichiers à une base de signatures (empreintes de virus connus), analyse le code et le comportement suspect par heuristique (instructions typiques, auto-modification, écritures dans les exécutables) et surveille en temps réel les actions des programmes, parfois dans un bac à sable.

Opération sur un fichier infectéEffet
Désinfecter (réparer)Retirer le code du virus et garder le fichier
Mettre en quarantaineIsoler le fichier dans une zone chiffrée où il ne peut plus s'exécuter
SupprimerEffacer le fichier
Ignorer / signalerLaisser (faux positif) ou envoyer à l'éditeur pour analyse
Le lien avec l'assembleur

Les analystes de malwares lisent du code désassemblé (outils comme Ghidra, IDA, x64dbg) : un malware n'est livré qu'en binaire. Savoir lire mov, push, call est la base de l'analyse et du reverse engineering.
