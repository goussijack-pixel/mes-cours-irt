Séries trigonométriques par la formule d'Euler, télescopage avec racines, Fourier de eˣ

3hL2 IRT
1

Énoncé au propre

Session 2 de mathématiques (3 h) — ESGIS, L2 IRT.

Exercice 1

Donner la somme de la série et en déduire sa convergence (on pourra utiliser la formule d'Euler), avec |q| < 1 :

  1. Σn=1∞ Uₙ = q sin α + q2 sin 2α + q3 sin 3α + ⋯
  2. Σn=1∞ uₙ = q cos α + q2 cos 2α + q3 cos 3α + ⋯

Exercice 2

Donner la somme de la série et en déduire sa convergence : Σn=1∞ (√n − 2√(n + 1) + √(n + 2)).

Exercice 3

  1. Montrer que le signal f(x) = ex, 0 ≤ x ≤ 1, est décomposable en série de Fourier.
  2. Construire sa courbe représentative.
  3. Construire la courbe de son prolongement par périodicité sur ℝ.
  4. Donner la fonction f*(x), ce prolongement.
  5. Donner la décomposition de ce signal en série de Fourier.
2

Corrigé détaillé

Essaie d’abord seul, puis ouvre chaque partie pour comparer.

Remarque sur l'énoncé
Attention

Le fichier original s'appelle « avec erreur » : dans la 2ᵉ série, il est écrit « α q3 cos 3α ». C'est une coquille : le terme général est clairement qⁿ cos(nα), comme dans la 1ʳᵉ série. On corrige dans ce sens.

Exercice 1 – Formule d'Euler et série géométrique
Idée

On regroupe les deux séries en une seule série complexe : Cₙ + i·Sₙ = Σ qⁿ(cos nα + i sin nα) = Σ (q eiα)ⁿ. C'est une série géométrique de raison z = q eiα.

|z| = |q| < 1, donc la série géométrique converge :

Σn≥1 zⁿ = z1 − z = q eiα1 − q eiα

On multiplie par le conjugué du dénominateur (1 − q e−iα) :

  • dénominateur : |1 − q eiα|2 = 1 − 2q cos α + q2 ;
  • numérateur : q eiα − q2 = (q cos α − q2) + i q sin α.

Partie imaginaire puis partie réelle :

Σ qⁿ sin(nα) = q sin α1 − 2q cos α + q2  ; Σ qⁿ cos(nα) = q cos α − q21 − 2q cos α + q2

Convergence : |qⁿ sin nα| ≤ |q|ⁿ et |qⁿ cos nα| ≤ |q|ⁿ, et Σ|q|ⁿ converge (géométrique, |q| < 1). Les deux séries sont donc absolument convergentes, donc convergentes. (Résultats vérifiés par calcul formel.)

Formule d'Euler

eiθ = cos θ + i sin θ ; (eiα)ⁿ = einα = cos nα + i sin nα (Moivre).

Exercice 2 – Télescopage double

On découpe : Uₙ = (√(n + 2) − √(n + 1)) − (√(n + 1) − √n). Posons vₙ = √(n + 1) − √n : alors Uₙ = vₙ₊₁ − vₙ.

Somme partielle : SN = Σn=1N (vₙ₊₁ − vₙ) = vN+1 − v₁ = (√(N + 2) − √(N + 1)) − (√2 − 1).

Or √(N + 2) − √(N + 1) = 1√(N + 2) + √(N + 1) → 0 (quantité conjuguée). Donc :

S = 1 − √2 ≈ −0,414

La série converge, de somme 1 − √2. (Contrôle numérique : la somme des 200 000 premiers termes vaut −0,4131.)

Piège classique

Ne pas écrire « √(N + 2) − √(N + 1) → ∞ − ∞ » : c'est une forme indéterminée qu'on lève avec la quantité conjuguée.

Exercice 3 – Fourier de ex sur [0 ; 1]

1. ex est continue, bornée (1 ≤ eˣ ≤ e) et croissante sur [0 ; 1] ⇒ conditions de Dirichlet vérifiées.

2. et 3. Courbe : arc exponentiel de (0 ; 1) à (1 ; e ≈ 2,72). Le prolongement 1-périodique recopie cet arc sur chaque [k ; k + 1[ (saut de e à 1 en chaque entier).

4. f*(x) = ex − E(x) (E = partie entière), c'est-à-dire f*(x) = ex − k si k ≤ x < k + 1.

5. T = 1, ω = 2π :

  • a₀ = ∫₀¹ eˣ dx = e − 1 ;
  • aₙ = 2∫₀¹ eˣ cos(2πnx)dx = 2(e − 1)1 + 4π2n2 ;
  • bₙ = 2∫₀¹ eˣ sin(2πnx)dx = −4πn(e − 1)1 + 4π2n2.
f*(x) = (e − 1) [ 1 + Σn≥1 2cos(2πnx) − 4πn sin(2πnx)1 + 4π2n2 ]
Astuce de calcul

Calculer d'un coup I = ∫₀¹ exe2iπnxdx = e1+2iπn − 11 + 2iπn = e − 11 + 2iπn, puis aₙ = 2 Re(I) et bₙ = 2 Im(I). On évite ainsi deux doubles intégrations par parties.

Aux entiers, la série converge vers e + 12 ≈ 1,86.

Série télescopique, divergence de Σ sin(nx), série de Fourier de x²

3hAGBOHOUTOL2 IRT
1

Énoncé au propre

Contrôle terminal de mathématiques (3 h) — ESGIS. Le rattrapage d'avril 2024 reprend exactement le même sujet.

Exercice 1

Donner la somme de la série Σn=1∞ Uₙ = 11·4 + 14·7 + 17·10 + ⋯ et en déduire sa convergence.

Exercice 2

  1. Montrer, par l'absurde, que la série Σn=1∞ sin(nx) diverge pour x ≠ kπ.
  2. Montrer qu'elle converge pour x = kπ, avec k ∈ ℤ.

Exercice 3

  1. Montrer que le signal f(x) = x2, 0 ≤ x ≤ 1, est décomposable en série de Fourier.
  2. Construire la courbe représentative de ce signal.
  3. Construire, dans un autre repère, la courbe du prolongement par périodicité sur ℝ de ce signal.
  4. En déduire la fonction f*(x), ce prolongement par périodicité sur ℝ.
  5. Donner la décomposition de ce signal en série de Fourier.
2

Corrigé détaillé

Essaie d’abord seul, puis ouvre chaque partie pour comparer.

Exercice 1 – Série télescopique

Terme général. Les premiers facteurs sont 1, 4, 7, … = 3n − 2 et les seconds 4, 7, 10, … = 3n + 1, donc :

Uₙ = 1(3n − 2)(3n + 1)

Décomposition en éléments simples. On cherche Uₙ = a3n − 2 + b3n + 1 : on trouve a = 13, b = −13. Ainsi

Uₙ = 13 ( 13n − 2 − 13n + 1 )

Somme partielle (tout se simplifie « en cascade ») : Sₙ = 13 [ (1 − 14) + (14 − 17) + ⋯ + (13n − 2 − 13n + 1) ] = 13 (1 − 13n + 1).

Limite : quand n → +∞, 13n + 1 → 0, donc S = 1/3. La suite des sommes partielles a une limite finie ⇒ la série converge et sa somme vaut 1/3.

Repérer une série télescopique

Si Uₙ = vₙ − vₙ₊₁ (ou un multiple), alors Sₙ = v₁ − vₙ₊₁ : tous les termes du milieu s'annulent.

À retenir

« Convergente » veut dire : la suite des sommes partielles Sₙ a une limite finie.

Exercice 2 – Σ sin(nx)

1. Divergence pour x ≠ kπ (par l'absurde). Supposons que la série converge. Alors son terme général tend vers 0 : sin(nx) → 0 (condition nécessaire de convergence).

  • On a aussi sin((n + 1)x) → 0. Or sin((n + 1)x) = sin(nx)cos x + cos(nx)sin x.
  • Les deux termes sin((n + 1)x) et sin(nx)cos x tendent vers 0, donc cos(nx)·sin x → 0.
  • Comme x ≠ kπ, on a sin x ≠ 0, donc cos(nx) → 0.
  • Mais alors sin2(nx) + cos2(nx) → 0 + 0 = 0, alors que cette somme vaut toujours 1. Contradiction.

⇒ Le terme général ne tend pas vers 0 : la série diverge grossièrement pour x ≠ kπ.

2. Convergence pour x = kπ. sin(n·kπ) = 0 pour tout n : tous les termes sont nuls, Sₙ = 0 pour tout n, donc la série converge et sa somme vaut 0.

Piège classique

« Uₙ → 0 » est nécessaire mais pas suffisant (Σ 1/n diverge alors que 1/n → 0). On l'utilise seulement dans un sens : si Uₙ ne tend pas vers 0, alors la série diverge.

Exercice 3 – Q1 : conditions de Dirichlet

f(x) = x2 sur [0 ; 1] est continue, bornée (0 ≤ f ≤ 1) et monotone (croissante) sur sa période. Elle vérifie donc les conditions de Dirichlet : on peut la développer en série de Fourier après prolongement 1-périodique.

Conditions de Dirichlet

Sur une période, la fonction est bornée, continue sauf en un nombre fini de points (sauts finis) et n'a qu'un nombre fini d'extremums. La série converge alors vers f(x) aux points de continuité, et vers la moyenne des limites à gauche et à droite aux points de saut.

Exercice 3 – Q2 à Q4 : courbes et prolongement

Le signal est un arc de parabole de (0 ; 0) à (1 ; 1). Le prolongement périodique de période T = 1 recopie cet arc sur chaque intervalle [k ; k + 1[ : on obtient des « dents de scie paraboliques ».

Q4 : pour tout réel x, f*(x) = (x − E(x))2, où E(x) est la partie entière de x. Autrement dit, f*(x) = (x − k)2 si k ≤ x < k + 1, avec k ∈ ℤ.

Exercice 3 – Q5 : décomposition en série de Fourier

Période T = 1, pulsation ω = 2πT = 2π.

Coefficients (période T)

a₀ = 1T∫ f ; aₙ = 2T∫ f(x)cos(nωx)dx ; bₙ = 2T∫ f(x)sin(nωx)dx

  • a₀ = ∫₀¹ x2 dx = 1/3 (valeur moyenne) ;
  • aₙ = 2∫₀¹ x2cos(2πnx)dx = 1π2n2 (deux intégrations par parties) ;
  • bₙ = 2∫₀¹ x2sin(2πnx)dx = −1πn.
f*(x) = 13 + Σn≥1 ( cos(2πnx)π2n2 − sin(2πnx)πn )

(Coefficients vérifiés par calcul formel.)

Intégration par parties pour aₙ

On pose u = x2, dv = cos(2πnx)dx : le crochet [x2sin(2πnx)/(2πn)]₀¹ est nul (sin(2πn) = 0). On recommence une 2ᵉ fois avec u = x. Pour bₙ, le premier crochet vaut −1/(2πn) car cos(2πn) = 1.

Aux points de saut

En x = k entier, f* saute de 1 à 0 : la série converge vers 1 + 02 = 1/2.

Normes équivalentes en dimension finie, norme 1 intégrale, limite à deux variables, forme différentielle

2hL2 IRT
1

Énoncé au propre

Contrôle de Topologie, continuité, différentielle — ESGIS, L2 IRT (2 h).

Exercice 1

Soit E un espace vectoriel (réel ou complexe) de dimension finie. On veut montrer que toutes les normes de E sont équivalentes.

  1. On commence par E = ℝⁿ.

    a) Soit N une norme sur ℝⁿ. Montrer qu'il existe un réel C tel que, pour tout x ∈ ℝⁿ, N(x) ≤ C‖x‖₁. b) Montrer que pour tous x, y ∈ ℝⁿ : |N(x) − N(y)| ≤ N(x − y) ≤ C‖x − y‖₁. En déduire que N est continue pour la topologie de ‖·‖₁. c) Montrer que A = {x ∈ ℝⁿ, ‖x‖₁ = 1} est compact pour la topologie de ‖·‖₁. d) Utiliser b et c pour montrer l'existence de C′ ∈ ℝ tel que ‖·‖₁ ≤ C′N.

  2. Conclure.

Exercice 2

E = espace vectoriel réel des fonctions continues de [0 ; 1] dans ℝ. Pour f ∈ E, ‖f‖₁ = ∫₀¹ |f(t)| dt.

  1. Montrer que ‖·‖₁ est une norme sur E.
  2. Soit fₙ(t) = tⁿ (n ∈ ℕ, t ∈ [0 ; 1]). Déterminer la limite de (fₙ) pour la norme ‖·‖₁.
  3. Quelle est la limite simple de (fₙ) sur [0 ; 1] ?

Exercice 3

f(x, y) = x2yx4 − 2x2y + 3y2 si (x, y) ≠ (0, 0) ; f(0, 0) = 0.

  1. Étudier la limite en l'origine de la restriction de f à la droite y = ax (a donné). Montrer que la restriction de f à toute droite passant par l'origine est continue.
  2. Calculer la limite à l'origine de la restriction de f à la parabole y = x2.
  3. Montrer que f n'a pas de limite à l'origine.

Exercice 4

On considère la forme différentielle ω = dx√(x2 + y2) + √(x2 + y2) − xy√(x2 + y2) dy. Montrer, en passant en coordonnées polaires, que ω est la différentielle totale d'une fonction U(ρ, θ), et donner l'équation des courbes U = constante.

2

Corrigé détaillé

Essaie d’abord seul, puis ouvre chaque partie pour comparer.

Exercice 1 – Q1a : N est dominée par ‖·‖₁

Soit (e₁, …, eₙ) la base canonique et x = Σ xᵢeᵢ. Par l'inégalité triangulaire et l'homogénéité de N : N(x) ≤ Σ |xᵢ| N(eᵢ) ≤ (max N(eᵢ)) × Σ|xᵢ| = C‖x‖₁, avec C = max₁≤ᵢ≤ₙ N(eᵢ).

Exercice 1 – Q1b : N est continue (et même lipschitzienne)
  • Inégalité triangulaire : N(x) = N((x − y) + y) ≤ N(x − y) + N(y), donc N(x) − N(y) ≤ N(x − y). En échangeant x et y : N(y) − N(x) ≤ N(y − x) = N(x − y). D'où |N(x) − N(y)| ≤ N(x − y).
  • Puis la question a) appliquée à x − y donne N(x − y) ≤ C‖x − y‖₁.

N est donc C-lipschitzienne pour ‖·‖₁, donc continue : si ‖x − y‖₁ < ε/C, alors |N(x) − N(y)| < ε.

Exercice 1 – Q1c : la sphère unité est compacte

A est :

  • bornée : tous ses points sont de norme 1 ;
  • fermée : A est l'image réciproque du fermé {1} par l'application continue x ↦ ‖x‖₁.

Pour montrer qu'elle est compacte, on utilise Bolzano-Weierstrass : soit (x(k)) une suite de A. Chaque coordonnée est bornée par 1, donc on peut extraire successivement (n fois) une sous-suite dont toutes les coordonnées convergent. La limite x vérifie ‖x‖₁ = 1, puisque A est fermée. Toute suite de A a donc une sous-suite convergente dans A ⇒ A est compacte.

Exercice 1 – Q1d : l'autre inégalité

N est continue (b) sur le compact A (c) : elle y est bornée et atteint ses bornes. Soit m = minA N = N(x₀) avec x₀ ∈ A.

  • x₀ ≠ 0 (car ‖x₀‖₁ = 1), donc m > 0 (séparation de la norme).
  • Pour x ≠ 0, x‖x‖₁ ∈ A, donc N(x‖x‖₁) ≥ m, c'est-à-dire N(x) ≥ m‖x‖₁.

D'où ‖x‖₁ ≤ C′N(x) avec C′ = 1/m (et c'est vrai aussi pour x = 0).

Exercice 1 – Q2 : conclusion

Pour toute norme N sur ℝⁿ : 1C′‖x‖₁ ≤ N(x) ≤ C‖x‖₁. Toute norme est équivalente à ‖·‖₁, donc (transitivité) deux normes quelconques sont équivalentes. Pour un espace E quelconque de dimension n, on choisit une base : l'application φ : 𝕂ⁿ → E est un isomorphisme, et N∘φ est une norme sur 𝕂ⁿ. On applique le résultat. ∎

À retenir

En dimension finie, toutes les normes sont équivalentes : elles définissent les mêmes ouverts, les mêmes suites convergentes, les mêmes compacts. C'est faux en dimension infinie (voir l'exercice 2).

Exercice 2 – Norme intégrale ‖·‖₁

1. Axiomes de norme.

  • ‖f‖₁ ≥ 0 (intégrale d'une fonction positive).
  • Séparation : si ∫₀¹|f| = 0 avec |f| continue et positive, alors |f| = 0 partout. Sinon, |f| > 0 sur un petit intervalle et l'intégrale serait > 0.
  • Homogénéité : ‖λf‖₁ = |λ|‖f‖₁.
  • Inégalité triangulaire : |f + g| ≤ |f| + |g|, et on intègre.
Piège classique

La continuité de f est indispensable pour la séparation : pour une fonction nulle sauf en un point, l'intégrale vaut 0 sans que la fonction soit nulle.

2. ‖fₙ − 0‖₁ = ∫₀¹ tⁿ dt = 1n + 1 → 0 : fₙ → 0 pour ‖·‖₁ (la fonction nulle).

3. Limite simple : pour 0 ≤ t < 1, tⁿ → 0 ; pour t = 1, tⁿ = 1 → 1. La limite simple est donc g(t) = 0 si t < 1, g(1) = 1 : elle n'est pas continue.

Ce que montre cet exercice

La limite pour ‖·‖₁ (fonction nulle) et la limite simple (fonction avec un saut) sont différentes. Pour ‖·‖_∞, la suite ne converge pas : ‖fₙ‖_∞ = 1 pour tout n. Les normes ‖·‖₁ et ‖·‖_∞ ne sont donc pas équivalentes sur E, qui est de dimension infinie.

Exercice 3 – Limite à deux variables

Le dénominateur s'écrit x4 − 2x2y + 3y2 = (x2 − y)2 + 2y2 > 0 hors de l'origine : f est bien définie.

1. Droites.

  • Droite y = ax (a ≠ 0) : f(x, ax) = ax3x4 − 2ax3 + 3a2x2 = axx2 − 2ax + 3a2 → 03a2 = 0.
  • a = 0 (axe des x) : f(x, 0) = 0. Axe des y (x = 0) : f(0, y) = 0.

Sur toute droite passant par l'origine, la limite vaut 0 = f(0, 0) : chaque restriction est continue.

2. Parabole y = x2 : f(x, x2) = x4x4 − 2x4 + 3x4 = x42x4 = 1/2.

3. Si f avait une limite L en (0, 0), toutes ses restrictions à des courbes passant par l'origine tendraient vers L. Or on obtient 0 sur les droites et 1/2 sur la parabole ⇒ f n'a pas de limite en l'origine (et n'est donc pas continue en 0).

Montrer qu'une limite n'existe pas

Trouver deux chemins vers le point qui donnent deux limites différentes. Les droites ne suffisent pas : il faut souvent un chemin « courbe » adapté aux puissances (ici y = x2, car x2y et y2 sont alors du même ordre).

Exercice 4 – Forme différentielle exacte

Passage en polaires : x = ρcos θ, y = ρsin θ, √(x2 + y2) = ρ ; dx = cos θ dρ − ρ sin θ dθ ; dy = sin θ dρ + ρ cos θ dθ.

  • dxρ = cos θρdρ − sin θ dθ ;
  • ρ − xyρdy = 1 − cos θρ sin θ(sin θ dρ + ρ cos θ dθ) = 1 − cos θρdρ + (1 − cos θ)cos θsin θdθ.

En additionnant :

  • terme en dρ : cos θ + 1 − cos θρ = 1ρ ;
  • terme en dθ : −sin2θ + cos θ − cos2θsin θ = cos θ − 1sin θ = −tanθ2.
ω = dρρ − tan(θ/2) dθ

Chaque coefficient ne dépend que de sa variable : ∂/∂θ(1/ρ) = 0 = ∂/∂ρ(−tan θ/2). La forme est fermée, donc exacte, et :

U(ρ, θ) = ln ρ + 2 ln|cos(θ/2)| + k = ln(ρ cos2(θ/2)) + k = lnρ + x2 + k

(car ρcos2(θ/2) = ρ1 + cos θ2 = ρ + x2). Vérification en cartésiennes : ∂/∂x ln(ρ + x) = 1ρ ✔ et ∂/∂y ln(ρ + x) = yρ(ρ + x) = ρ − xyρ ✔.

Courbes U = Cte : ρ + x = k (k > 0) ⇒ √(x2 + y2) = k − x ⇒ y2 = k2 − 2kx : des paraboles d'axe Ox, de foyer l'origine, tournées vers les x négatifs.

Distance φ∘d, métrique d/(1+d), norme infinie et convergence uniforme

2hL2 IRT
1

Énoncé au propre

Rattrapage du contrôle continu de Topologie, continuité, différentielle — ESGIS, L2 IRT.

Exercice 1

Soit (X, d) un espace métrique.

  1. Soit φ : ℝ⁺ → ℝ⁺ croissante telle que, pour tous u, v ∈ ℝ⁺ : φ(u) = 0 ⇔ u = 0, et φ(u + v) ≤ φ(u) + φ(v). Pour x, y ∈ X, on pose δ(x, y) = φ(d(x, y)). Montrer que δ est une distance sur X.
  2. On suppose (X, d) non borné (∀A ∈ ℝ, ∃x, y ∈ X, d(x, y) > A). On pose δ(x, y) = d(x, y)1 + d(x, y).

    a) Montrer que δ est une métrique sur X. b) Montrer que d et δ donnent la même topologie sur X. c) Montrer que d et δ ne sont pas équivalentes.

Exercice 2

E = espace des fonctions continues sur [0 ; 1] à valeurs réelles. Pour f ∈ E : ‖f‖_∞ = supt∈[0;1] |f(t)|.

  1. Rappeler pourquoi ‖f‖_∞ est bien défini pour tout f ∈ E.
  2. Montrer que ‖·‖_∞ est une norme sur E.
  3. Soit (fₙ) une suite de E qui converge vers f pour ‖·‖_∞. Montrer que f ∈ E.
  4. Soit (gₙ) une suite de E qui converge simplement vers g. A-t-on nécessairement g ∈ E ?
2

Corrigé détaillé

Essaie d’abord seul, puis ouvre chaque partie pour comparer.

Exercice 1 – Q1 : δ = φ∘d est une distance

On vérifie les 4 axiomes :

  • Positivité : δ(x, y) = φ(…) ∈ ℝ⁺.
  • Séparation : δ(x, y) = 0 ⇔ φ(d(x, y)) = 0 ⇔ d(x, y) = 0 ⇔ x = y.
  • Symétrie : d(x, y) = d(y, x), donc δ(x, y) = δ(y, x).
  • Inégalité triangulaire : d(x, z) ≤ d(x, y) + d(y, z). Comme φ est croissante : φ(d(x, z)) ≤ φ(d(x, y) + d(y, z)). Comme φ est sous-additive : φ(d(x, y) + d(y, z)) ≤ φ(d(x, y)) + φ(d(y, z)). Donc δ(x, z) ≤ δ(x, y) + δ(y, z). ∎
À retenir

Les deux hypothèses servent chacune une fois dans l'inégalité triangulaire : la croissance, puis la sous-additivité.

Exercice 1 – Q2a : d/(1 + d) est une métrique

On applique la question 1 avec φ(u) = u1 + u :

  • φ ≥ 0 et φ(u) = 0 ⇔ u = 0 ;
  • croissante : φ′(u) = 1(1 + u)2 > 0 ;
  • sous-additive : u + v1 + u + v = u1 + u + v + v1 + u + v ≤ u1 + u + v1 + v (on agrandit chaque fraction en diminuant son dénominateur).

Donc δ est une distance. ∎

Exercice 1 – Q2b : même topologie

φ est une bijection strictement croissante et continue de [0 ; +∞[ sur [0 ; 1[, de réciproque ψ(s) = s1 − s. Pour les boules :

  • B_δ(x, r) = B_d(x, r1 − r) pour 0 < r < 1 (et B_δ(x, r) = X si r ≥ 1) ;
  • B_d(x, r) = B_δ(x, r1 + r).

Toute boule d'une distance est donc une boule de l'autre, centrée au même point. Un ensemble est ouvert pour d ⇔ il contient une d-boule autour de chacun de ses points ⇔ il contient une δ-boule autour de chacun de ses points ⇔ il est ouvert pour δ. Mêmes ouverts : même topologie. ∎

Exercice 1 – Q2c : d et δ ne sont pas équivalentes

« Équivalentes » signifie : ∃α, β > 0 tels que α d ≤ δ ≤ β d.

  • On a toujours δ ≤ d (car 1 + d ≥ 1).
  • Mais l'autre inégalité d ≤ 1αδ est impossible : δ < 1 donnerait d(x, y) < 1α pour tous x, y, alors que X est non borné. Il suffit de prendre A = 1/α : il existe x, y avec d(x, y) > 1/α. Contradiction. ∎
Piège classique

« Même topologie » (topologiquement équivalentes) n'implique pas « équivalentes » (au sens des inégalités). Cet exercice en est l'exemple type.

Exercice 2 – Norme infinie

1. f est continue sur le segment [0 ; 1], qui est compact : f est bornée et atteint ses bornes (théorème de Weierstrass). Le sup existe, c'est même un max.

2. Positivité : évidente. Séparation : sup|f| = 0 ⇒ f = 0. Homogénéité : sup|λf| = |λ| sup|f|. Inégalité triangulaire : pour tout t, |f(t) + g(t)| ≤ |f(t)| + |g(t)| ≤ ‖f‖_∞ + ‖g‖_∞, puis on passe au sup.

3. Limite uniforme de fonctions continues (méthode « ε/3 »). Soient t₀ ∈ [0 ; 1] et ε > 0.

  • On choisit n tel que ‖fₙ − f‖_∞ < ε/3.
  • fₙ est continue en t₀ : il existe η > 0 tel que |t − t₀| < η ⇒ |fₙ(t) − fₙ(t₀)| < ε/3.
  • Alors |f(t) − f(t₀)| ≤ |f(t) − fₙ(t)| + |fₙ(t) − fₙ(t₀)| + |fₙ(t₀) − f(t₀)| < ε.

Donc f est continue en tout t₀ : f ∈ E. ∎

4. Non. Contre-exemple : gₙ(t) = tⁿ, continues, convergent simplement vers g = 0 sur [0 ; 1[ et g(1) = 1. g n'est pas continue en 1 ⇒ g ∉ E.

À retenir
  • Convergence uniforme (pour ‖·‖_∞) : la continuité passe à la limite.
  • Convergence simple : la continuité peut se perdre.

Module 1 — Suites numériques

Suite

Une liste infinie de nombres u₀, u₁, u₂, … rangés dans l'ordre. On la définit soit explicitement (uₙ = 1n + 1), soit par récurrence (u₀ = 0 et uₙ₊₁ = √(2 + uₙ)).

MajoréeIl existe M avec uₙ ≤ M pour tout nUne inégalité, souvent par récurrence

Convergenteuₙ → ℓ, un nombre finiCalcul de limite, théorèmes ci-dessous
DivergentePas de limite finie (→ ±∞, ou oscille comme (−1)ⁿ)–

Les suites de référence

SuiteTerme généralLimite
Arithmétique (raison r)uₙ = u₀ + nr+∞ si r > 0, −∞ si r < 0
Géométrique (raison q)uₙ = u₀qⁿ0 si |q| < 1 ; diverge si |q| > 1 ou q = −1

Calculer une limite

Les 4 réflexes
  • Fraction de polynômes : factorise par le plus haut degré. 2n2 + 3n2 − 1 = 2 + 3/n21 − 1/n2 → 2.
  • Croissances comparées : ln n ≪ nα ≪ qⁿ (q > 1) ≪ n!. Donc n2ⁿ → 0 et ln nn → 0.
  • Quantité conjuguée pour les racines : √(n + 1) − √n = 1√(n + 1) + √n → 0.
  • Limite remarquable : (1 + 1n)ⁿ → e.
Les 3 théorèmes à citer
  • Théorème des gendarmes : si vₙ ≤ uₙ ≤ wₙ et vₙ, wₙ → ℓ, alors uₙ → ℓ. Exemple : −1n ≤ sin nn ≤ 1n donc sin nn → 0.
  • Suite monotone bornée : toute suite croissante et majorée converge (et toute suite décroissante minorée).
  • Suites adjacentes : si (uₙ) croît, (vₙ) décroît et vₙ − uₙ → 0, elles convergent vers la même limite.

La suite récurrente type : uₙ₊₁ = f(uₙ)

u₀ = 0 et uₙ₊₁ = √(2 + uₙ)

1. Majorée par 2 (récurrence). u₀ = 0 ≤ 2. Si uₙ ≤ 2, alors uₙ₊₁ = √(2 + uₙ) ≤ √4 = 2. 2. Croissante (récurrence). u₁ = √2 ≥ u₀. Si uₙ₊₁ ≥ uₙ, alors 2 + uₙ₊₁ ≥ 2 + uₙ, et la racine est croissante, donc uₙ₊₂ ≥ uₙ₊₁. 3. Converge : croissante et majorée. 4. Limite : ℓ vérifie ℓ = √(2 + ℓ), donc ℓ2 − ℓ − 2 = 0, soit ℓ = 2 ou ℓ = −1. Comme uₙ ≥ 0, ℓ = 2.

Chercher ℓ avant de prouver la convergence

L'équation ℓ = f(ℓ) ne donne que les candidats. Il faut d'abord prouver que la suite converge (monotone + bornée), sinon on peut trouver une « limite » d'une suite qui n'en a pas.

Module 2 — Séries numériques : l'idée

Série

À partir d'une suite (uₙ), on fabrique la suite des sommes partielles Sₙ = u₁ + u₂ + ⋯ + uₙ. La série Σuₙ converge si (Sₙ) a une limite finie S : c'est la somme de la série.

Une série, c'est une addition qui ne s'arrête jamais. La question : est-ce que le total se stabilise ?

Le test de départ (condition nécessaire)

Si Σuₙ converge, alors uₙ → 0. Donc si uₙ ne tend pas vers 0, la série diverge grossièrement. Attention : la réciproque est fausse (Σ1/n diverge alors que 1/n → 0).

Les séries de référence

SérieConverge si…Somme
Géométrique Σqⁿ (n ≥ 0)|q| < 111 − q
Géométrique Σqⁿ (n ≥ 1)|q| < 1q1 − q
Riemann Σ1nαα > 1(pas de formule simple en général)
Harmonique Σ1njamaisdiverge

Les critères de convergence (séries à termes positifs)

  1. Comparaison : si 0 ≤ uₙ ≤ vₙ et Σvₙ converge, alors Σuₙ converge.
  2. Équivalents : si uₙ ~ vₙ (termes positifs), les deux séries ont la même nature.
  3. D'Alembert : si uₙ₊₁/uₙ → ℓ, la série converge pour ℓ < 1, diverge pour ℓ > 1 (aucune conclusion si ℓ = 1).
  4. Cauchy : si ⁿ√uₙ → ℓ, même conclusion.
  5. Séries alternées (Leibniz) : si |uₙ| décroît vers 0, Σ(−1)ⁿ|uₙ| converge.

Module 3 — Calculer la somme : les séries télescopiques

C'est l'exercice 1 de presque tous les CT. L'idée : écrire uₙ comme une différence vₙ − vₙ₊₁, pour que tout s'annule en cascade.

Le télescope

Si uₙ = vₙ − vₙ₊₁ alors Sₙ = v₁ − vₙ₊₁. Si vₙ → ℓ, la série converge et S = v₁ − ℓ.

CT 2023 — Σ 11·4 + 14·7 + 17·10 + ⋯

1. Terme général. Les facteurs avancent de 3 : 1, 4, 7, 10… = 3n − 2. Donc uₙ = 1(3n − 2)(3n + 1). 2. Décomposition en éléments simples. 1(3n − 2)(3n + 1) = 13(13n − 2 − 13n + 1). (Vérifie : la différence des deux fractions vaut 3(3n − 2)(3n + 1).) 3. Le télescope. Sₙ = 13(1 − 14 + 14 − 17 + ⋯ − 13n + 1) = 13(1 − 13n + 1). 4. Limite. 13n + 1 → 0 donc S = 1/3 : la série converge.

Session 2 — Σ (√n − 2√(n + 1) + √(n + 2))

On coupe le −2√(n + 1) en deux : uₙ = (√n − √(n + 1)) − (√(n + 1) − √(n + 2)) = vₙ − vₙ₊₁ avec vₙ = √n − √(n + 1). Or vₙ = −1√n + √(n + 1) → 0 (on multiplie par la quantité conjuguée). Donc S = v₁ − 0 = 1 − √2.

Repérer un télescope

Fraction rationnelle → éléments simples. Racines carrées ou logarithmes qui reviennent décalés → regrouper les termes par paires.

Module 4 — Séries trigonométriques et formule d'Euler

Euler

eiα = cos α + i sin α, donc cos α = Re(eiα) et sin α = Im(eiα). Et (eiα)ⁿ = einα.

Σ qⁿ cos nα et Σ qⁿ sin nα (avec |q| < 1)

L'astuce : les deux séries sont la partie réelle et la partie imaginaire d'une seule série géométrique, de raison z = q eiα, avec |z| = |q| < 1.

  1. C + iS = Σ (q eiα)ⁿ = z1 − z (géométrique, n ≥ 1).
  2. On multiplie en haut et en bas par le conjugué 1 − q e−iα : le dénominateur devient |1 − z|2 = 1 − 2q cos α + q2.
  3. Le numérateur vaut z − |z|2 = q cos α − q2 + i q sin α.
  4. On sépare : C = q cos α − q21 − 2q cos α + q2 et S = q sin α1 − 2q cos α + q2.

Σ sin(nx) : convergence ou divergence ?

  • Pour x = kπ : tous les termes sont nuls, la série converge (somme 0).
  • Pour x ≠ kπ, par l'absurde : si elle convergeait, sin(nx) → 0, donc aussi sin((n + 1)x) → 0. Or sin((n + 1)x) = sin(nx)cos x + cos(nx)sin x, donc cos(nx) sin x → 0, et comme sin x ≠ 0, cos(nx) → 0. Mais alors sin2(nx) + cos2(nx) → 0, alors que cette quantité vaut toujours 1. Contradiction : la série diverge.

Module 6 — Intégrales généralisées

Quand une borne est infinie ou que la fonction explose en une borne, on définit l'intégrale comme une limite : ∫₁+∞ f = limX→+∞ ∫₁X f. Si la limite est finie, l'intégrale converge.

Les intégrales de Riemann (à connaître par cœur)
  • ∫₁+∞ dxxα converge ⇔ α > 1 (et vaut 1α − 1).
  • ∫₀¹ dxxα converge ⇔ α < 1 (et vaut 11 − α).
  • ∫₀+∞ e−axdx = 1a pour a > 0.
∫₁+∞ dxx2

∫₁X x−2dx = [−1x]₁X = 1 − 1X → 1 : l'intégrale converge et vaut 1.

Comparaison (fonctions positives)

Si 0 ≤ f ≤ g et ∫g converge, alors ∫f converge. Si f ~ g en la borne à problème, même nature. Exemple : 1x2 + 1 ≤ 1x2 sur [1 ; +∞[ donc ∫₁+∞ dxx2 + 1 converge.

Le pont entre séries et intégrales

Pour f positive décroissante, Σf(n) et ∫₁+∞f(x)dx ont la même nature. C'est pour cela que Σ1nα et ∫₁+∞dxxα convergent toutes les deux exactement quand α > 1 (et que Σ1n diverge, comme ∫dxx = ln X → +∞).

Module 7 — Séries de Fourier

L'idée

Tout signal périodique raisonnable est une somme de sinusoïdes : une valeur moyenne + des cosinus et des sinus de fréquences multiples. C'est ce que fait ton téléphone quand il compresse un MP3 ou une photo JPEG.

Les formules (période T, pulsation ω = 2πT)

Coefficients

a₀ = 1T∫ f(x)dx (la valeur moyenne) aₙ = 2T∫ f(x) cos(nωx) dx et bₙ = 2T∫ f(x) sin(nωx) dx (intégrales sur une période) f*(x) = a₀ + Σn≥1 (aₙ cos(nωx) + bₙ sin(nωx))

Conditions de Dirichlet (« décomposable en série de Fourier »)

Si f est périodique et de classe C¹ par morceaux (continue par morceaux, dérivée continue par morceaux, un nombre fini de sauts par période), sa série de Fourier converge en tout point vers f(x⁺) + f(x⁻)2 : la valeur de f là où f est continue, le milieu du saut ailleurs.

Raccourcis de parité

f paire ⇒ tous les bₙ = 0. f impaire ⇒ a₀ = 0 et tous les aₙ = 0. Regarde toujours la parité avant de calculer.

Le cas du CT : f(x) = x2 sur [0 ; 1]

Dirichlet. On prolonge f par périodicité de période T = 1. Sur chaque période, f est un polynôme (C¹) ; il y a un saut à chaque entier (de 1 à 0). Donc f est C¹ par morceaux : elle est décomposable.

Prolongement. f*(x) = (x − ⌊x⌋)2, où ⌊x⌋ est la partie entière : on « ramène » x dans [0 ; 1[ puis on élève au carré. Coefficients (T = 1, ω = 2π) :

  • a₀ = ∫₀¹ x2dx = 13 ;
  • aₙ = 2∫₀¹ x2cos(2πnx)dx = 1π2n2 (deux intégrations par parties) ;
  • bₙ = 2∫₀¹ x2sin(2πnx)dx = −1πn.
Résultat

f*(x) = 13 + Σn≥1 ( cos(2πnx)π2n2 − sin(2πnx)πn )

La vérification qui rapporte des points

En x = 0, la série vaut 13 + 1π2Σ1n2 = 13 + 1π2·π26 = 12 : c'est bien le milieu du saut entre 1 et 0. Bonus : tu viens de retrouver Σ1n2 = π26.

Le cas eˣ (session 2) sans double IPP

Calcule d'un coup I = ∫₀¹ eˣ e2iπnxdx = e − 11 + 2iπn, puis aₙ = 2 Re(I) = 2(e − 1)1 + 4π2n2 et bₙ = 2 Im(I) = −4πn(e − 1)1 + 4π2n2. Et a₀ = e − 1.

Module 8 — Normes et distances

Norme

Une application N : E → ℝ⁺ qui mesure la « taille » d'un vecteur, avec 3 règles :

  1. Séparation : N(x) = 0 ⇔ x = 0 ;
  2. Homogénéité : N(λx) = |λ| N(x) ;
  3. Inégalité triangulaire : N(x + y) ≤ N(x) + N(y).
Distance

d : X × X → ℝ⁺ avec d(x, y) = 0 ⇔ x = y, d(x, y) = d(y, x) et d(x, z) ≤ d(x, y) + d(y, z). Toute norme donne une distance : d(x, y) = N(x − y).

Les trois normes de ℝⁿ

NormeFormuleBoule unité dans ℝ²
‖x‖₁|x₁| + ⋯ + |xₙ|un losange
‖x‖₂ (euclidienne)√(x₁2 + ⋯ + xₙ2)un disque

Normes équivalentes

N₁ et N₂ sont équivalentes s'il existe α, β > 0 tels que α N₁ ≤ N₂ ≤ β N₁. Elles définissent alors les mêmes ouverts, les mêmes suites convergentes.

Dans ℝⁿ : ‖x‖_∞ ≤ ‖x‖₂ ≤ ‖x‖₁ ≤ n‖x‖_∞. Et le grand théorème (exercice 1 du CC) : en dimension finie, toutes les normes sont équivalentes.

En dimension infinie, ce n'est plus vrai

Sur E = C([0 ; 1]) (fonctions continues), deux normes classiques :

  • ‖f‖₁ = ∫₀¹ |f(t)|dt (l'aire sous |f|) ;
  • ‖f‖_∞ = sup |f(t)| (le point le plus haut). Elle est bien définie car une fonction continue sur un segment est bornée et atteint ses bornes.
fₙ(t) = tⁿ

‖fₙ‖₁ = ∫₀¹ tⁿdt = 1n + 1 → 0 : (fₙ) tend vers 0 pour ‖·‖₁. Mais ‖fₙ‖_∞ = 1 pour tout n : elle ne tend pas vers 0 pour ‖·‖_∞. Les deux normes ne sont donc pas équivalentes.

Module 9 — Ouverts, fermés, compacts

Boule ouverte

B(a, r) = {x : d(a, x) < r}, tous les points à distance strictement inférieure à r de a.

NotionDéfinition simple
OuvertAutour de chacun de ses points, on peut placer une petite boule entièrement dedans
FerméSon complémentaire est ouvert ; de façon équivalente, il contient la limite de toutes ses suites convergentes
BornéIl tient dans une boule
CompactToute suite a une sous-suite qui converge dans l'ensemble
Dans ℝⁿ (dimension finie)

Compact ⇔ fermé et borné. Exemple : la sphère A = {x : ‖x‖₁ = 1} est fermée (image réciproque de {1} par une fonction continue) et bornée, donc compacte.

Le théorème des bornes atteintes

Une fonction continue sur un compact est bornée et atteint son minimum et son maximum. C'est l'outil clé pour prouver l'équivalence des normes : N est continue et ne s'annule pas sur la sphère unité compacte, donc elle y a un minimum m > 0, d'où N(x) ≥ m‖x‖₁.

La limite simple de tⁿ n'est pas continue

Pour t ∈ [0 ; 1[, tⁿ → 0 ; pour t = 1, tⁿ = 1. La limite simple vaut 0 sur [0 ; 1[ et 1 en 1 : elle est discontinue. Une limite simple de fonctions continues n'est donc pas forcément continue.

À retenir

Une limite uniforme de fonctions continues est continue. Preuve en 3 morceaux (le « ε/3 ») : |f(x) − f(a)| ≤ |f(x) − fₙ(x)| + |fₙ(x) − fₙ(a)| + |fₙ(a) − f(a)|, chaque morceau rendu < ε/3.

Module 11 — Fonctions de deux variables : limites et continuité

Pour une limite en (0, 0), on peut arriver par une infinité de chemins. Si deux chemins donnent deux limites différentes, il n'y a pas de limite.

Prouver qu'il n'y a pas de limite
  • Essaie les droites y = ax.
  • Si elles donnent toutes la même valeur, essaie une parabole y = x2 (ou x = y2) : c'est souvent elle qui « casse » tout.
  • Deux chemins, deux limites différentes ⇒ pas de limite.
CC — f(x, y) = x2yx4 − 2x2y + 3y2

Droites y = ax (a ≠ 0). f(x, ax) = ax3x4 − 2ax3 + 3a2x2 = axx2 − 2ax + 3a2 → 03a2 = 0. Pour a = 0, f(x, 0) = 0. Sur toute droite, la restriction tend vers 0 = f(0, 0) : elle est continue. Parabole y = x2. f(x, x2) = x4x4 − 2x4 + 3x4 = 12. Conclusion. 0 ≠ 12 : f n'a pas de limite en (0, 0), alors qu'elle est continue sur chaque droite. Piège classique !

Prouver qu'il y a une limite

Passe en polaires x = ρ cos θ, y = ρ sin θ et majore |f| par une quantité qui ne dépend que de ρ et tend vers 0.

Dérivées partielles et différentielle

  • ∂f/∂x : on dérive par rapport à x en traitant y comme une constante (et inversement).
  • f est différentiable en a si f(a + h) = f(a) + df_a(h) + o(‖h‖) : elle s'approche par une application linéaire.
  • C¹ (dérivées partielles continues) ⇒ différentiable ⇒ continue. La réciproque est fausse.

Module 12 — Formes différentielles

Forme différentielle

ω = P(x, y)dx + Q(x, y)dy. Elle est exacte s'il existe U telle que dU = ω, c'est-à-dire ∂U/∂x = P et ∂U/∂y = Q.

Le test (théorème de Poincaré)

Sur un ouvert « sans trou » (étoilé), ω est exacte ⇔ ∂P∂y = ∂Q∂x.

Trouver U en 3 étapes
  • Vérifie ∂P/∂y = ∂Q/∂x.
  • Intègre P par rapport à x : U = ∫P dx + φ(y).
  • Dérive ce U par rapport à y, compare à Q pour trouver φ′(y), puis φ.
ω = 2xy dx + (x2 + 3y2) dy

∂P/∂y = 2x = ∂Q/∂x : exacte. U = x2y + φ(y) ; ∂U/∂y = x2 + φ′(y) = x2 + 3y2 donc φ(y) = y3. U = x2y + y3 + C.

Quand les √(x2 + y2) envahissent tout

Passe en coordonnées polaires : ρ = √(x2 + y2), dx = cos θ dρ − ρ sin θ dθ, dy = sin θ dρ + ρ cos θ dθ. La forme devient A(ρ, θ)dρ + B(ρ, θ)dθ, souvent bien plus simple (c'est l'exercice 4 du CC).

Topologie

  • Distance : positivité, séparation, symétrie, inégalité triangulaire.
  • Norme : séparation, homogénéité ‖λx‖ = |λ|‖x‖, inégalité triangulaire.
